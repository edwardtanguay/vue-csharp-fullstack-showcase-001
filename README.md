# vue-csharp-fullstack-showcase-001

This is a fullstack C#/Vue application that runs in one directory. 

## frontend

-   Vue 3
-   TypeScript
-   Vue Router
-   Pinia - _state management_
-   Zod - _validation_
-   Tailwind & Sass
-   nodemon - _hot reloading_
-   concurrently - _runs backend/frontend with one command_
-   ESLint/Prettier

## backend API

-   ASP .NET Core
-   C#

## setup

-   `npm i`
-   `npm run dev` - _starts both backend and frontend_
